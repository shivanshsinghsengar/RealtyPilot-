# RealtyPilot

AI-powered CRM for real estate plot sales in Bhopal, Madhya Pradesh.

## Features

- **Lead Management**: Kanban board, CSV import, advanced filtering, duplicate detection
- **Site Visits**: Scheduling, tracking, calendar view, feedback collection  
- **Smart Scoring**: Automated lead quality scoring (0-100) based on 6 factors
- **Analytics**: Funnel visualization, conversion rates, source performance
- **Projects**: Inventory management with RERA details and pricing
- **Security**: Authentication, row-level security, audit logs

## Tech Stack

Next.js 14, TypeScript, Supabase, Tailwind CSS, Vercel
